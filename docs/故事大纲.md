## 1. 一句话真相

AkaneRei 不是在和一个逐渐安静的朋友群聊天，而是在死后被「回声」平台的实验性服务困在账号里：平台利用他**未断的语音连接**作为回返窗口，每天 04:08 用云端同步重置他的记忆，让他以「第一次聊天」的身份反复上线；他的朋友们则被迫成为实验的「容器」，208 天无法告别。

更深一层的真相（作者层）：AkaneRei 在 2026-04-08 04:08 坠亡——死因是他为抢修断掉的语音线路爬到阳台外，坠落。**他为了不断线而死。** 平台把「永不掉线」当作礼物送给他，实际是把他锁在账号里。他早在 208 天前就该「已离线」。

## 2. 叙事层级（开发纪律）

| 层级 | 含义 | 允许出现的位置 |
| --- | --- | --- |
| 故事真相 | 作者设定中真实发生的事 | 真相页、结局演出、本文 |
| 档案证实 | 玩家能用平台材料闭合的事实 | 聊天记录、日志、凭证、章节演出 |
| 故意留白 | 材料不能证明，或不应替角色判断的部分 | 游戏内明确保留不确定性 |

举例：汐泊诺思 208 天来每晚给「不认识她的他」发消息，这是故事真相；平台材料只能证明连续 208 天的同文案消息、发送时间戳与读取状态。游戏内不能把「她在等他想起她」写成平台的技术结论。感情性质（至交/恋人）由材料留白。

## 3. 平台表面：ECHOS「回声」

### 3.1 伪装界面

- 应用名：`回声 ECHOS`，表面是一款面向年轻人的聊天 App，口号：**「别让重要的人掉线」**（这句话本身是伏笔）。
- 界面元素必须像真的聊天软件：会话列表、已读回执（单勾/双勾/灰色/蓝色）、在线状态（在线/离线/隐身/「刚刚在线」）、资料卡、群公告、平台公告、账号安全中心、用户协议、客服号「回声小助手」。
- 开局第一屏不是营销页，而是登录后的会话列表，一切看起来正常，唯一异常是**所有会话的时间戳都停在 04:08**。
- 隐藏指令：`不要按顺序读。按你怀疑的内容去找。` 不写成教程横幅，藏进用户协议的免责声明角落，或由 N9Rtz 的一句悄悄话给出。
- 全平台默认无背景音乐，只保留消息提示音；「零信号」标记被检索到并收到检索告警后，才启用悬疑氛围曲；「已注销」账号、身份侦测阶段换用惊悚氛围曲（音乐只分层不承载线索，素材授权同参考项目流程）。

### 3.2 平台机制（玩家可见）

- **云端同步**：每天 04:08 自动同步，覆盖本地聊天记录与「关系记忆」。同步期间聊天记录出现「已由云端恢复」的横幅。
- **在线状态异常**：AkaneRei 的账号在 04:08 前后出现「正在输入…」却永不发出消息。
- **已读回执异常**：某些消息永远显示「未读」，即使发送者确认对方「刚刚在线」。
- **「零信号」标记**：一个只剩一格灰色的波形条图标（正常波形为四格），出现在用户协议页脚、注销页、404 页、平台公告角落。检索它 → 触发监视性恐怖演出。
- **《连接与断开守则》**：用户协议，规则怪谈式增补——「本平台所有联系人均为虚拟形象」「你从未认识任何人」「若你记得不该记得的事，请点击这里忘记」。阅读时持续向下滚动会不断生成新的机械校正条款，页面没有终点。
- **账号状态**：在线 / 离线 / 隐身 / 注销 / **「迁移至冷备份服务器」**（表面用语，实为封存）。

### 3.3 幕后组织

- **回声网络（ECHOS Inc.）**：表面运营方。供应商档案、平台公告、客服话术均为表面。
- **赫兹实验室（HZ）**：回声网络的实际控制方。掌握账号状态改写、云端同步、冷备份迁移与「零信号」标签权限。供应商投标文件反复出现内部口号：**「连接该连接的，切断该切断的。」**
- **静默会**（作者层）：赫兹背后研究「亡者回返」的组织。理论：遗物（账号）、未结关系（未说完的话）、重复的信息系统（04:08 同步）三者齐备即形成回返窗口；联系人列表是容器，聊天记录是唤醒路径，同步是记忆一致性校正。游戏内组织绝不直接自白。

## 4. 核心人物

### 4.1 AkaneRei（主角，已死）

- 真名：**晓倩**（后期揭示；游戏早期只呈现网名。「倩」音近 Akane）。
- 平台 ID：`AkaneRei`（Rei/零，「赤色的零号」）；前代账号：`Aka-0`（⚠ 对应参考的 CS-046 暗线）。
- 表层人设：深夜活跃的「夜猫子」，群里的气氛组，永远秒回。
- 故事真相：2026-04-08 04:08 坠亡，死前正在和 N9Rtz 通宵语音，语音因信号中断，他为抢修线路坠亡。
- 循环特征：每晚 04:08「重新登录」，记忆被云端同步清零；已发生 208 个循环。
- 叙事边界：游戏内先呈现时间戳异常、重复的「第一次聊天」、被撤回的自动归因；玩家交叉核对后可亲自确认自己就是事故死者。只有真相页明确「同一意识」与循环机制。
- 玩家确认身份前，精确检索 `Aka-0` 不返回普通档案，而是触发无法终止的「正在输入…」索引延展与零信号接管（监视性恐怖演出，不授予证据）。

### 4.2 N9Rtz（夜间人 / 幸存者，事故夜的语音对象）

- 真名：**巴印**（锁定，但**游戏内不揭示**；仅作者设定与开发文档）。
- 网名含义：Night 的变体，夜行生物。
- 事故夜与 AkaneRei 通宵语音的人。事故后一直在线但不再说话——**已读不回 208 天**。
- 故事真相：他活着，但被困在「最后一通电话」里；他听到了事故全过程，却因为怕失去而不敢再开口。
- 第一章的「救援」对象：玩家通过复原事故夜时间线，让他开口承认「那天我在电话里听到了一切」，他随后给出下一章的线索（提到 LuvisDrug 曾警告过他）。
- 保留问题：他那天具体听到了什么，录音无法完全证明；他的沉默是愧疚还是别的，材料不替他回答。

### 4.3 LuvisDrug（调查者，被「注销」）

- 真名：**李铭泽**（锁定，但**游戏内不揭示**；仅作者设定与开发文档）。
- 网名含义：Love is Drug，对真相/对 AkaneRei 的执念如瘾。
- 最早发现「AkaneRei 已死但账号还在说话」的人。追查服务器日志、资金流与「零信号」标记后被平台「注销账号」——**但注销后账号仍在写入**（残留会话，对应参考顾长河的留言令牌）。
- 他的 4 篇调查笔记（⚠ 对应周明川 4 篇日记）记录：无目的的好友迁移、资金归拢、不需要设备也能联通的账号、处置记录早于状态修改。
- 恐怖演出：登录残留账号读完笔记 → 「你是谁」「你还在吗」→ 平台请求摄像头核验 → 零信号波形膨胀 → 「快断开」→ 返回登录（对应参考「我发现你了」与眨眼红眼）。
- 保留问题：他是被平台「注销」还是自己注销后仍放不下，材料可两读。

### 4.4 汐泊诺思（守候者，情感锚点）

- 真名：**王镓铭**（锁定，但**游戏内不揭示**；仅作者设定与开发文档。资料卡与密码契约仍基于网名「汐泊诺思」）。
- 对应参考的林若岚。AkaneRei 最亲近的人（至交/恋人性质由材料留白）。
- 208 天来每晚给 AkaneRei 发同一条日常消息：**「今天也是第一次见你。」**（因为云端同步后他确实不认识她）。
- 保存着糖盒式信物：一个共享歌单「汐泊与零的歌单」+ 一个约定（⚠ 草案：约定内容待定，倾向「如果有一天你不再上线，我会把歌单听完」）。
- 中后期账号被平台标记「不健康状态」并「迁移至冷备份服务器」下线——因为她记得太多。
- 第三章的情感高潮：冷备份里封存着 208 条「今天也是第一次见你」+ 一条未发出的告别语音 + AkaneRei 生前没发出去的草稿（游戏内不出现实名）。
- 坏结局中，她在第 209 次「第一次聊天」后不再期待回复。

### 4.5 灰色账号：回声小助手（观察者）

- 对应参考的 HMO-ADMIN。官方客服号「回声小助手」，每个新用户都「有」它，看起来无害。
- 208 天前「添加」了 AkaneRei；头像是一个灰色波形条；状态永远显示「刚刚在线」/「正在输入…」但从不真正回复。
- 精确检索它的内部编号会触发监视演出：输入中状态永不结束、平台公告被改写、界面被灰色波形覆盖。演出不授予证据。

### 4.6 群里的其他人（噪音与红鲱鱼）

- 「全员群」中的潜水成员：`APXS`、`Rtwyzz`、`Roy`、`已注销用户` 等成员，提供真实但无关的日常消息（对应参考 0702/1302 干扰记录），用于自然排除，不写「与主线无关」的提示语。三人的资料卡可检索（APXS/Rtwyzz/Roy），但都通向死胡同——干扰项。作者设定其真名分别为刘睿航、李磊、张贤德，但**游戏内不揭示**。
- 一个隐藏的第 5 案件相关者：`Aka-0` 账号本体——208 天前曾在群里、朋友们以为它是机器人/客服，直到后期交叉核对确认它也是 AkaneRei（晓倩）的更早周期（CS-046 暗线）。

## 5. 四个案件（章节）

调查台账按「聊天对象」归并为四个章节。对应事实推导完成前，章节只显示对象名；完成后揭示章节名：`已读不回`、`已注销`、`冷备份`、`最后在线`。

### CASE 01：已读不回（N9Rtz / 事故夜）——开场章

平台材料可以证明：

- 2026-04-08 03:00 起 AkaneRei 与 N9Rtz 的通宵语音通话记录，04:08 中断。
- N9Rtz 最后一条消息（04:07）显示「已读」，此后 208 天 0 条消息。
- 一段事故夜录音：含通话人声、环境底噪、断裂音与坠落撞击声（分轨素材，⚠ 对应参考的声纹净化）。
- 04:08 前后两人的在线状态时间线（在线/离线/「刚刚在线」的切换序列）。
- 平台把事故夜记录「整理」成「通话中断，无异常」的自动摘要。

玩家操作：

1. **事件时间线重建**（⚠ 对应参考的搜救路线）：把消息、已读回执、状态变更排成 04:08 前后的事件序列。错误排列返回「证据不连续」提示，不抹掉已排好的节点。
2. **录音分轨净化**：排除底噪与平台提示音，保留人声与关键断点（对应参考的四轨声纹）。
3. 完成时间线后，N9Rtz 在群聊中开口，承认事故夜他在电话里听到一切，给出下一章线索（「LuvisDrug 查过这个平台，然后他就不见了」）。

故事真相：N9Rtz 是事故夜的亲历者（电话那头），208 天不敢开口。
平台责任：04:08 的同步把事故记录归一为「无异常」。
保留问题：电话那头到底发生了什么，录音不能完全证明；N9Rtz 的沉默成因留白。

### CASE 02：已注销（LuvisDrug / 平台内部犯罪）——调查章

平台材料可以证明：

- LuvisDrug 账号 2026-06-02 被「注销」，但注销后仍有写入（残留会话、本地缓存）。
- 他的调查轨迹：17 名好友的「无目的迁移」→ 资金归拢到赫兹文化基金 → 「零信号」标签规律 → 赫兹通讯残片（使用「观察者」「回返窗口」「连接一致性」等非用户用语）。
- 《连接与断开守则》的存在与自动增补机制（规则怪谈式，页面无终点）。
- 注销审计显示处置记录早于状态修改（清除流程预先存在）。

玩家操作：

1. 解出 LuvisDrug 残留本地账号密码（⚠ 草案：凭据备注 = 波形图解码出的频率段 + 一条语音的静音规律摩斯码 + 账号 ID 拼接，去掉分隔符连续输入；细化阶段锁定具体值）。
2. 阅读 4 篇调查笔记 → 触发身份侦测崩坏演出（「你是谁」「你还在吗」→ 摄像头核验（拒绝不阻断）→ 零信号波形膨胀 → 「快断开」）。
3. 重新登录 AkaneRei 后，平台将《连接与断开守则》直接列为下一份待办。

故事真相：LuvisDrug 因追查平台实验而被平台「注销」——像墙里的周明川，只是这次的「墙」是服务器冷备份。
平台责任：注销流程预先存在；守则持续压制认知。
保留问题：LuvisDrug 是被灭口还是「自愿消失」，材料两可。

### CASE 03：冷备份（汐泊诺思 / 被封存的告别）——情感章

平台材料可以证明：

- 汐泊诺思账号 208 天来每晚 23:58 发送同文案消息，读取状态异常（永远「未读」但发送者可见「刚刚在线」）。
- 账号被标记「不健康状态」并「迁移至冷备份服务器」后下线；迁移单没有目的地说明。
- 冷备份舱内封存 208 条「今天也是第一次见你」+ 一条未发出的告别语音 + 一条 AkaneRei 未发送的草稿（时间戳 04:07）。
- 共享歌单的存在（歌单最后修改时间 2026-04-08 04:06）。

玩家操作：

1. **破拆冷备份**（⚠ 对应参考的 1104 封墙破拆）：解出备份舱密码（草案候选：共享歌单名 / 208 条消息规律 / 汐泊诺思资料卡字段，细化锁定）。
2. 播放告别语音与草稿 → 情感高潮演出：汐泊诺思 208 天来每晚对「不认识她的他」说话；「今天也是第一次见你」从日常问候变成悼词。
3. 取得平台实验的旁证（她保存着事故当晚他「最后上线」的时间戳截图）。

故事真相：汐泊诺思是最放不下的人；平台以「不健康」为由封存她，防止她「教会」AkaneRei 真相。
平台责任：`FRIEND-KEEP` 策略保持未断关系关联却不向前台暴露，警告 AkaneRei「不得动用私情」。
保留问题：她与 AkaneRei 的关系性质、告别语音的完整内容，材料不替她下结论。

### CASE 04：最后在线（AkaneRei 自己 / 真相章）——终章

平台材料可以证明：

- 事故死亡者实名哈希与 AkaneRei 账号哈希一致；紧急联系人指向「汐泊诺思」。
- 账号于 2026-04-09 被批量创建，无注册流程（对应参考「事故次日被创建」）。

## 9. 设计纪律（红线，镜像参考 AGENTS.md）

- 平台表面必须是像真的聊天软件，不是恐怖游戏菜单；恐怖通过小状态变化升级（时间戳异常、破碎标题、零信号标记、账号状态、已读回执、云同步、身份侦测、记忆覆盖）。
- 证据先于结论：玩家通过记录与交叉核对发现身份，不把「报事人身份核验」答案预填为结论；不把未验证的联系人名字用作检索公安/急救记录的门槛（对应参考：N9Rtz 名字来自通话记录，急救回执来自平台外来源，两者只在玩家的临时核对表单汇合）。
- 不把超自然写成系统结论：游戏内材料只能证明「路线、令牌写入、声音、身份冲突」，不能证明「幽灵做了某事」；顾小满式救援（如有）不得写成工程结论。
- 平台知道得比承认得多：通过预生成的守则、字段压制、账号变更、资金、警告来表现，而不是反派独白。
- 全真相只在真相页 `/truth/` 与剧透文档中直说。
- 不在普通档案中提前写明 AkaneRei 死亡、Aka-0、汐泊诺思感情或平台机制的完整答案。
- 平台警告应体现压制与知情，不写成作者替玩家总结真相。
- 感情留白：汐泊诺思与 AkaneRei 的关系、LuvisDrug 的动机，材料不替角色下结论。
- 媒体可用性：语音/视频失败必须有手动核验回退，永不永久阻断进度；摄像头拒绝/缺失有确定性回退。
- 刷新、后退/前进、账号切换、`遗忘`（账号安全中心清除本机进度）行为符合预期。
- 好结局完整播放后才解锁全部档案补读；坏结局不显示该入口。
